# Hudhud 🐦

Eine Lern-App für Kinder: arabische Buchstaben und Vokale, Schreiben mit dem Finger (mit Schreib-Animation), erste Wörter, Quiz, der Juz' ʿAmma mit deutscher Bedeutung und Rezitation, das deutsche ABC und Zahlen. Lernen bringt Sterne, mit Sternen geht es auf den Spielplatz. Ein Elternbereich setzt ein tägliches Zeitlimit.

Alle Daten (Name, Fortschritt) bleiben im Browser des Geräts. Die App sendet nichts an einen Server.

Installation auf dem iPhone: die Seite in Safari öffnen › Teilen › „Zum Home-Bildschirm“.

Quellen: Korantext Hafs (King-Fahd-Komplex) und deutsche Bedeutung von Frank Bubenheim und Nadeem Elyas über [fawazahmed0/quran-api](https://github.com/fawazahmed0/quran-api). Rezitation: Mahmoud Khalil Al-Husary über everyayah.com.
